Loan Default Prediction
An end to end ML application for loan risk prediction using XGBoost, SHAP and Streamlit.

Live Demo
https://loan-default-prediction-bhybshy7n3bv75w3ssltf8.streamlit.app/

Performance
ROC AUC: 0.7191
PR AUC: 0.3265
Input Features: 31
Transformed Features: 915

Tech Stack
Python
Pandas
Scikit learn
XGBoost
SHAP
Streamlit
Features
Loan risk prediction
Class probabilities
SHAP based explanations
Interactive Streamlit interface
Complete preprocessing pipeline

Run Locally
git clone https://github.com/Vanshi-sys/loan-default-prediction.git
cd loan-default-prediction
pip install -r requirements.txt
streamlit run app.py
